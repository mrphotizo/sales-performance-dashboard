Overview
This project presents an interactive Sales Performance Dashboard built in Power BI to analyze revenue trends, product performance, regional sales, and key customers. It is designed to provide quick, actionable insights that support data-driven decision-making.

📌 Key Metrics
Total Revenue: $45.69M
Total Quantity Sold: 291 units

📈 Key Insights
Revenue peaked in February, followed by a decline in March and recovery in April
Laptop is the top-performing product, contributing the highest revenue
Abuja is the leading region in overall sales
A small group of customers (e.g., Aisha, David, Mary) drive a significant portion of revenue

⚙️ Features
Interactive filters (Month, Region, Product)
Dynamic visualizations for trend and comparison analysis
Top customers ranking
Clear KPI indicators for quick performance tracking

🛠️ Tools Used
Power BI
Microsoft Excel
